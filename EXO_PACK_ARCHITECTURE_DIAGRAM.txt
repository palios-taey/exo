┌─────────────────────────────────────────────────────────────────────────────┐
│                       CONVERSION PIPELINE                                   │
└─────────────────────────────────────────────────────────────────────────────┘

Step 1: Analysis (1-2 seconds)
├─ Load config.json → num_hidden_layers = 80
├─ Parse model.safetensors.index.json → weight_map (1062 tensors)
└─ Calculate splits: 80 layers ÷ 2 = [0-39], [40-79]

Step 2: Tensor Loading (5-10 minutes)
├─ Read 16 safetensors files from HF cache
├─ Filter tensors by layer range
└─ Load into memory (140 GB → 70 GB filtered)

Step 3: FP8 Conversion (10-15 minutes)
├─ Convert bfloat16 → float8_e4m3fn
└─ 70B params × 2 bytes → 70B params × 1 byte

Step 4: Shard Creation (3-5 minutes)
├─ Stage 0: Combine layers 0-39 into single safetensors
├─ Stage 1: Combine layers 40-79 into single safetensors
└─ Pad to 16MB alignment

Step 5: Checksum & Metadata (2-3 minutes)
├─ Compute SHA256 for each shard
├─ Generate manifest.json
└─ Generate per-stage metadata.json

Total: 20-35 minutes (Llama-3-70B, 2-stage, FP8)

Optimization: Process stages in parallel → 10-20 minutes
