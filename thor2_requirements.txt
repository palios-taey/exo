# ============================================================================
# KNOWN ISSUES AND WORKAROUNDS
# ============================================================================
#
# 1. NVRTC API Changes:
#    - CUDA 13.0 modified NVRTC API
#    - Some tinygrad versions may need patching
#    - Workaround: Use tinygrad 0.11.0 or later
#
# 2. Blackwell PTX Compilation:
#    - Compute capability 10.1 requires PTX 9.0+
#    - Requires nvidia-nvjitlink 13.0+
#    - Set DEVICE=CUDA environment variable
#
# 3. mgbe Network Interfaces:
#    - Jetson Thor uses mgbe (25GbE) interfaces
#    - Patch applied to exo/helpers.py for detection
#    - Interface priority: 8 (higher than Thunderbolt)
#
# 4. Unified Memory:
#    - Thor uses unified memory architecture
#    - No separate VRAM allocation needed
#    - Memory shared between CPU and GPU
#
# ============================================================================
# PERFORMANCE NOTES
# ============================================================================
#
# - Blackwell GPU: ~10 TFLOPS FP32, ~20 TFLOPS FP16, ~40 TFLOPS INT8
# - 25GbE networking: ~3 GB/s theoretical, ~2.5 GB/s practical
# - Unified memory: Lower latency than discrete GPU
# - NVMe storage: Fast model loading from local cache
