TECHNICAL NOTES
===============================================================================

MANUAL DISCOVERY LOOP (every 5 seconds):
1. Load peers from config file (with hot-reload support)
2. For each peer: Create handle if new, health check if existing
3. If healthy: Add to known_peers dict
4. If unhealthy: Skip this iteration, retry in 5 seconds
5. Sleep 5 seconds, repeat

KEY DIFFERENCE FROM UDP:
- UDP: Remove peer if not seen within 30s timeout
- Manual: Retry unhealthy peer every 5s forever (eventual consistency)

ADVANTAGE FOR LONG LOADS:
- Even if peer unhealthy for 18-33min during load
- Manual discovery retries every 5s
- Once load completes and peer becomes healthy
- Peer automatically added back to cluster
